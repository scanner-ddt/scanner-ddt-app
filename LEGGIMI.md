# Scanner DDT – app Android

App per scansionare DDT e ticket pesa con lo scanner di documenti di Google (ML Kit),
leggere il N. Progressivo e mettere il PDF in coda per l'invio automatico via Gmail
(script Apps Script "Scanner DDT").

La compilazione è automatica: a ogni caricamento GitHub crea il file
**ScannerDDT.apk** nella sezione *Releases → ultima*.
